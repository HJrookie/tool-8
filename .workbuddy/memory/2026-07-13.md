# 2026-07-13 工作日志

## 项目梳理 + 撰写 README.md
- 项目本质：基于 Vue 3 + Vite + Element Plus 的「梅花易数·数字起卦」纯前端卜卦工具（原 package.json name 为 `tool`）。
- 核心逻辑在 `src/components/Form.vue` + `src/utils/index.js`：
  - 上/mid/bottom 三输入框分别用于 动爻 / 上卦 / 下卦 推算。
  - 动爻 = top%6（0→6）；上卦 = mid%8（0→8）；下卦 = bottom%8（0→8）。
  - 动爻>3 变上卦，否则变下卦；变化编码查 `guaChangeMap`，卦名查 `guaMap`。
  - `mingtainjiHrefMap` 提供每卦跳转「明天机」详解页链接。
- 用中文完整 README 覆盖原英文模板（含功能、技术栈、目录、起卦算法、数据结构、配置、待完善）。
- 注：端口 5177、监听 0.0.0.0；pnpm 管理依赖。

## 用户澄清：正确的使用方式
- 这是**起《易经》卦象**的工具，使用方法为：**从下往上**依次输入 **3 个三位数字**。
- 即填表顺序：先填「下」框（bottom=下卦）→ 再「中」框（mid=上卦）→ 最后「上」框（top=动爻）。
- 已据此修正 README 的「功能特性 / 简介 / 使用说明」，强调"从下往上 + 三位数字"约定。
